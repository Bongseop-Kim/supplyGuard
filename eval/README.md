## 6.4 정답 정의

라벨 없이 잴 수 있게, 변경 후 상태에서 **재사용 없이 처음부터 판정한 결과**를 정답으로 둔다.
재사용했는데 처음부터 판정하면 상태가 달라지는 건 = 누락. 다시 판정했는데 이전과 같은 건 = 불필요 재판정.
`file` 단위는 affected 판정만 근거 파일 단위로 무효화하고 not_affected·uncertain은 코드가 조금이라도 바뀌면 다시 판정한다(`backend/supplyguard/manage/reuse.py`).
